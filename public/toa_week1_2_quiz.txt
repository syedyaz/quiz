#title: Theory of Automata Quiz (Weeks 1–2)
#time: 20
#marks: 0.5

1. A coin-operated turnstile starts in the Locked state and receives the inputs: coin, push, push, coin, coin, push. In which state does it end?
A) Unlocked
B) Locked*
C) It depends on how many people walked through
D) No state, because the input is invalid

2. Which statement best describes the memory of a finite automaton?
A) An unbounded tape that it can read and write
B) A single stack
C) A counter that can grow without limit
D) Only its current state, chosen from a finite set of states*

3. Which of these languages is context-free but NOT regular?
A) Balanced parentheses*
B) All binary strings ending in 01
C) Valid identifiers in C
D) All strings over {a, b}

4. An automaton accepts exactly the binary strings that end in 1. Which of these strings does it accept?
A) ε (the empty string)
B) 110
C) 1011*
D) 10

5. Let u = ab and v = baa. What is the concatenation vu?
A) abbaa
B) baaab*
C) aabba
D) baaba

6. Which of these is NOT a substring of the string abb?
A) ε
B) ab
C) bb
D) ba*

7. A DFA accepts binary strings with an even number of 1s. Its states are E (even) and O (odd), the start state is E and F = {E}. Which string does it REJECT?
A) 111*
B) ε
C) 11
D) 0110

8. A DFA accepts strings over {a, b} that contain ab: q0 goes to q1 on a and stays on b; q1 stays on a and goes to q2 on b; q2 loops on a and b. What is the sequence of states for the input bba?
A) q0, q1, q2, q2
B) q0, q0, q1, q2
C) q0, q0, q0, q1*
D) q0, q1, q1, q1

9. For any DFA M = (Q, Σ, δ, q₀, F), when is the empty string ε in L(M)?
A) When F is empty
B) When the start state q₀ is an accepting state*
C) When M has a trap state
D) When δ(q₀, a) = q₀ for some symbol a

10. A complete DFA for 'strings that start with a' over Σ = {a, b} has the states q0, q1 and a trap state qd. How many transitions does its transition function δ have?
A) 3
B) 4
C) 9
D) 6*
